# Number Plate OCR using OpenCV

## Features
- Vehicle image input
- Number plate detection
- Image preprocessing
- Tesseract OCR
- Exact-match evaluation
- CSV results

## Technologies
- Python
- OpenCV
- Tesseract OCR
- Pytesseract

## How to Run
1. Install Python
2. Install OpenCV
3. Install Pytesseract
4. Install Tesseract OCR
5. Run plate_ocr.py
